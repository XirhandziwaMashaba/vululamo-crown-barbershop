# Vululamo Crowns — Talent Forge Assessment

A responsive fictional barber shop website built for the Talent Forge Junior Full-Stack Developer practical assessment.

## Features
- Responsive multi-section professional website
- Services and pricing
- Barber profiles
- Working booking form with service, barber, date and time
- Dynamic appointment preview
- Dynamic Google Calendar event generation
- Apple Calendar-compatible `.ics` generation
- Booking confirmation modal with reference number
- Promotional popup/modal
- Terms & Conditions page
- Mobile navigation
- Accessible labels and buttons

## Run locally
Open `index.html` directly, or use any static server.

Example:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.

## Deploy
Upload the folder to a static host such as Vercel, Netlify or GitHub Pages. The final assessment submission should contain only the resulting public website URL.
